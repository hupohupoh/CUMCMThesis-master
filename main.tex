\begin{abstract}
本文基于 MIT--Stanford 公开锂离子电池循环老化数据集，围绕“快充策略--充电时间--寿命衰减”的定量关系，依次完成数据整理、量化建模、寿命预测与策略优化四项递进任务。

对于问题一，系统整理了 124 个 A123 18650 磷酸铁锂电池的充电策略参数（第一阶段倍率 $C_1$、切换 SOC $Q_1$、第二阶段倍率 $C_2$）、循环寿命、SOH 衰减曲线与充电时间，完成异常循环清洗、格式归一化与协议类型区分；寿命分布跨度约 15 倍（148--2235），并识别出典型长寿命策略（中高 SOC 区间倍率温和，$C_2\le 4.4$C）与短寿命策略（$C_2\ge 5.5$C）。

对于问题二，建立 $\log_{10}$ 寿命与策略参数的多变量回归模型及“SOC 剂量”模型，量化各因素贡献：第二阶段倍率 $C_2$ 是主要的负向倍率因素（含批次差异标准化系数 $-0.039$，偏相关 $-0.249$），充电时间与寿命正相关（偏相关 $+0.376$）；单位高倍率电量在中高 SOC 区间的寿命损伤比低 SOC 区间高约 16\%（$m_2$ 系数 $-0.424$ vs $m_1$ $-0.367$），验证了不同 SOC 区间高倍率影响的显著差异。

对于问题三，从早期循环提取 SOH 衰减率、波动、充电时间漂移等特征，建立梯度提升寿命预测模型，5 折$\times$8 次重复交叉验证下以前 20 个循环预测寿命的 MAPE 达 14.7\%（$R^2=0.77$）；特征重要性分析表明充电时间特征（首循环值与波动）为主导特征，近中期 SOH 预测误差小于 1.2\%。

对于问题四，在数据驱动优化基础上引入 PyBaMM 电化学仿真进行机理验证，构建校准充电时间模型与剂量型寿命响应面，在实验覆盖邻域内做多目标网格寻优得到 Pareto 前沿，膝点策略 3.6C(80\%)-3.6C（充电 13.3 min、实测寿命 2081）；进一步突破两段式局限，搜索任意 SOC 分段的多段阶梯充电策略，最优三段式 3C→45\%→2C→65\%→0.8C 预测寿命达 3868 次（较最优两段式提升 160\%），并经 PyBaMM 单循环析锂验证外推安全性，实现了从“已知策略择优”到“新策略设计创新”的方法论升级。

\keywords{电池快充\quad 循环寿命\quad 剂量模型\quad 寿命预测\quad PyBaMM\quad 多段充电}
\end{abstract}

% ==================== 一、问题重述 ====================
\section{问题重述}

锂离子电池在循环使用过程中可用容量逐渐下降，通常以健康状态（SOH）表征老化程度：
\[
\mathrm{SOH}=\frac{Q_{\mathrm{current}}}{Q_{\mathrm{initial}}}\times 100\%,
\]
当 SOH 降至 80\% 时认为达到寿命终止条件。快充能显著缩短补能时间，但较高充电电流会加剧极化、热效应与副反应，加快容量衰减。不同 SOC 区间内电池对充电电流的敏感程度不同：低 SOC 区间采用较大电流有助于缩短充电时间，而中高 SOC 区间继续高倍率充电则可能加剧老化。

本数据集为 MIT--Stanford 公开锂离子电池循环老化数据集\upcite{ref1}，共 124 个 A123 18650 磷酸铁锂电池（额定容量 1.1 Ah），分三个批次（41/43/40）。充电采用分段快充策略，可表示为：先以 $C_1$ 倍率从 0\% SOC 充电至 $Q_1$，再以 $C_2$ 倍率从 $Q_1$ 充电至 80\% SOC，最后以 1C 恒流--恒压（CC-CV）模式充电至满电。不同电池的差异主要体现于 $C_1$、$Q_1$、$C_2$ 三个参数。需要说明的是，本文中 “C” 表示充放电倍率（即以额定容量为基准的电流倍数，如 3.6C 表示充电电流为 3.6$\times$1.1 A）。

需要解决以下四个问题：
\begin{enumerate}
\item 对原始循环实验数据进行整理，提取各电池的充电策略、充电时间、SOH 变化及循环寿命等关键信息；给出典型长寿命策略和短寿命策略，并从充电倍率、SOC 区间和充电时间角度进行初步解释。
\item 建立充电策略参数与电池寿命衰减之间的定量关系模型，重点分析不同 SOC 区间内充电电流倍率对寿命的影响，量化 $C_1$、$Q_1$、$C_2$ 及充电时间的贡献，并给出各因素及交互作用的影响程度排序。
\item 基于给定快充策略下电池早期循环数据，建立寿命预测模型，预测电池未来 SOH 衰减趋势或达到寿命终止条件时的循环次数，并讨论早期循环长度与策略参数的作用。
\item 设计兼顾充电时间与寿命衰减的快充策略优化方法，给出推荐策略，并与典型长寿命、短寿命策略对比，说明其合理性、适用范围和可能的外推风险。
\end{enumerate}

% ==================== 二、问题分析 ====================
\section{问题分析}

问题一的核心是数据整理与规律初探：需先解析三段式快充策略参数、校准充电时间单位、清洗异常循环，再对寿命分布做分批次统计，并从多参数角度解释长短寿命差异。

问题二的核心是因果量化：寿命跨度达约 15 倍，需用回归模型解耦 $C_1$、$Q_1$、$C_2$、充电时间的贡献。考虑到实验设计存在混杂与批次差异，采用含批次虚拟变量的多变量回归，并构造“SOC 剂量”变量 $m_1=C_1Q_1/100$、$m_2=C_2(80-Q_1)/100$ 直接检验不同 SOC 区间高倍率影响的差异。

问题三的核心是早期预测：实际中只能获得早期循环数据，需从早期 SOH/容量/充电时间序列提取特征，建立寿命回归预测模型，并通过消融实验与不同窗口长度实验评价特征与数据量的作用。

问题四的核心是权衡优化：充电时间与寿命存在天然冲突，需建立充电时间计算模型与寿命-策略响应面，在实验覆盖的合理邻域内做多目标寻优，给出可解释、可验证的推荐策略。

四个问题逐层递进，形成“整理 $\rightarrow$ 量化 $\rightarrow$ 预测 $\rightarrow$ 优化”的完整链条，前一问题的输出作为后一问题的输入。整体研究流程见图 \ref{fig:fig20}；正文第 5$\sim$9 节按问题顺序组织，各问题的小问依次在对应小节中解决，条理清晰、便于查证。

% ==================== 三、模型假设 ====================
\section{模型假设}

基于对数据集结构与电池老化机理的分析，提出如下假设：

\begin{enumerate}
\item 各电池初始状态一致，SOH 以首循环放电容量为基准归一化；80\% SOH 为寿命终止（EOL）阈值。
\item 充电时间定义为快充段（0$\sim$80\% SOC）耗时，不含 80\%$\sim$100\% 的 CC-CV 补电阶段。
\item 批次内环境（温度、夹具、工艺）条件一致；批次间差异通过批次差异项吸收，不假定批次间可互换。
\item 不同 SOC 区间的高倍率充电对老化的贡献具有可加性（剂量叠加假设），且效应在观测参数范围内近似线性。该假设是剂量模型（第 \ref{sec:phys} 节）的基础，第 \ref{sec:imp} 节的回归分析与第 \ref{sec:interact} 节的交互检验进一步验证了其近似合理性。
\item 优化仅在实验覆盖的参数水平及其合理邻域内进行，不向未经验证的高倍率或 SOC 区间外推。该假设确保优化结果的可验证性与工程安全性。
\end{enumerate}

上述假设在相应章节中均通过数据或残差诊断进行了检验，若有违背之处已在模型的适用范围与不足中予以说明。

\subsection{关键提取与清洗}

\textbf{（1）异常循环清洗。}个别循环放电容量相对前值突变超过 20\%（如 data\_1\_cell0 循环 11），判定为测量异常并剔除。采用“相邻循环相对突变 $>20\%$”的稳健判据逐循环扫描，并将异常点置空、不计入后续统计。

\textbf{（2）数据质量筛选。}结合第 2.1 节的口径处理，剔除未完成循环（如 data\_3\_cell23、data\_3\_cell32 的 cycle\_life 缺失）及测试后期容量未降至 0.88 Ah 阈值、数据采集异常的电池，最终保留 124 个有效电池。

\textbf{（3）充电时间单位校准。}依据“充电至 80\% SOC 的理论时间”验证，确认单位均为分钟（如 3.6C(80\%) 理论 $0.8/3.6\times60=13.33$ min，实测 13.34 min），并确认充电时间对应快充段（0$\sim$80\% SOC）耗时。

\item \textbf{$C_2$ 是主要的负向倍率因素（$r=-0.418$）。}第二阶段充电覆盖从 $Q_1$ 到 80\% SOC 的中高电量区间，该区间内负极电位更接近析锂电位，高倍率充电会显著加剧负极析锂与电解液分解。短寿命策略（如 1C(4\%)-6C、2C(10\%)-6C）的共同特征正是 $C_2\ge5.5$C。

\item \textbf{充电时间与寿命正相关（$r=0.350$）。}各策略充电至 80\% SOC 的时间差异不大（约 11$\sim$14 min），但充电时间更长的策略（通常倍率更温和）寿命更长；寿命差异达约 15 倍，说明决定寿命的关键是充电电流在 SOC 轴上的分布方式，而非单纯的快慢。
\end{enumerate}

\section{问题二：充电策略参数对寿命衰减影响的量化模型}

\subsection{物理模型}\label{sec:phys}

定义两个阶段的充电电量：
\begin{equation}\label{eq:dose}
m_1 = \frac{C_1\cdot Q_1}{100},\qquad
m_2 = \frac{C_2\cdot (80-Q_1)}{100}.
\end{equation}
以二者为自变量对 $\log_{10}$（循环寿命）做回归，两个系数均为显著负值：$m_1$ 的系数为 $-0.367$，$m_2$ 的系数为 $-0.424$，即充电电量越多、寿命越短（模型 $R^2=0.635$）。

$m_1$ 与 $m_2$ 本质上都是充电电量，若损伤只取决于电量，二者系数应当相等；而 $m_2$ 的系数更负（$-0.424$ vs $-0.367$），说明相同的电量在高 SOC 区间造成的损伤更大，即单位电量的损伤随 SOC 变化。为此引入 SOC 损伤权重函数 $f(\mathrm{SOC})$，将充电电量修正为有效损伤电量：
\begin{equation}\label{eq:weight}
m' = C\cdot \int_{s_1}^{s_2} f(s)\,\mathrm{d}s,
\end{equation}
则两阶段充电的总有效损伤电量为
\begin{equation}\label{eq:deff}
D_{\mathrm{eff}} = C_1\cdot F(Q_1) + C_2\cdot\left[F(80)-F(Q_1)\right],
\end{equation}
其中 $F(s)=\int_0^s f(t)\,\mathrm{d}t$ 为累积损伤函数，回归方程相应修正为
\begin{equation}\label{eq:deff-reg}
\log_{10}(L) = \beta_0 - \beta\cdot D_{\mathrm{eff}}.
\end{equation}
据此拟合出两种候选函数形式（表 \ref{tab:fsoc}）：线性型形式简洁、便于计算；对数饱和型随 SOC 增长初期上升较快、后期趋于平缓，对应高 SOC 时损伤受传质限制而趋于饱和。

\subsection{各充电参数对寿命衰减的影响}

将第 \ref{sec:phys} 节的物理模型展开为策略参数 $C_1$、$Q_1$、$C_2$ 的显式形式。由线性权重函数 $f(\mathrm{SOC})=1+0.43\,\mathrm{SOC}/100$ 得累积损伤函数 $F(s)=s+0.215\,s^2/100$（$s$ 以百分数计），代入式 \eqref{eq:deff}，总有效损伤电量可写成
\begin{equation}\label{eq:deff-explicit}
D_{\mathrm{eff}} = C_1\left(Q_1 + \frac{0.215\,Q_1^2}{100}\right) + C_2\left(80-Q_1 + \frac{0.215(80^2-Q_1^2)}{100}\right).
\end{equation}
对三个策略参数求偏导，即得各参数对有效损伤电量的边际影响：
\begin{equation}\label{eq:pd-c1}
\frac{\partial D_{\mathrm{eff}}}{\partial C_1} = F(Q_1) = Q_1 + \frac{0.215\,Q_1^2}{100} > 0,
\end{equation}
\begin{equation}\label{eq:pd-c2}
\frac{\partial D_{\mathrm{eff}}}{\partial C_2} = F(80)-F(Q_1) = 80-Q_1 + \frac{0.215(80^2-Q_1^2)}{100} > 0,
\end{equation}
\begin{equation}\label{eq:pd-q1}
\frac{\partial D_{\mathrm{eff}}}{\partial Q_1} = (C_1-C_2)\,f(Q_1).
\end{equation}
据此逐项分析各参数的影响（数值见表 \ref{tab:marginal}）：

\textbf{1. 第一阶段充电倍率 $C_1$。}$\partial D_{\mathrm{eff}}/\partial C_1=F(Q_1)>0$，增大 $C_1$ 始终增加有效损伤、缩短寿命。其边际效应 $F(Q_1)$ 是第一阶段全程 $[0,Q_1]$ 的累积损伤，由于低 SOC 区间权重 $f$ 较小（$f(0)=1$），该值相对有限（样本均值 $F(Q_1)/100\approx0.49$）；数值上由剂量模型，$C_1$ 每提高 1C，$\log_{10}$ 寿命约下降 0.16（寿命约衰减 30\%）。$C_1$ 的独立效应在统计上常不显著，主要源于低 SOC 区间析锂风险低，以及批次 1 内 $C_1$ 与 $Q_1$ 的强负相关（实验设计混杂）。

\textbf{2. 阶段切换 SOC $Q_1$。}$\partial D_{\mathrm{eff}}/\partial Q_1=(C_1-C_2)f(Q_1)$，其方向由两阶段倍率的相对大小决定，这是物理模型相对简单回归的关键补充：
\begin{itemize}
\item 当 $C_1>C_2$（先快后慢）时，$\partial D_{\mathrm{eff}}/\partial Q_1>0$，增大 $Q_1$ 把更多高倍率电量推迟到更高 SOC 区间，寿命缩短；
\item 当 $C_1<C_2$（先慢后快）时，$\partial D_{\mathrm{eff}}/\partial Q_1<0$，增大 $Q_1$ 将高倍率电量限制在低 SOC 区间，寿命延长；
\item 当 $C_1=C_2$（单一均匀倍率）时，$\partial D_{\mathrm{eff}}/\partial Q_1=0$，切换点不影响寿命。
\end{itemize}

\textbf{3. 第二阶段充电倍率 $C_2$。}$\partial D_{\mathrm{eff}}/\partial C_2=F(80)-F(Q_1)>0$，增大 $C_2$ 缩短寿命。其边际为中高 SOC 区间 $[Q_1,80\%]$ 的累积损伤，该区间权重 $f$ 较大（$f(80\%)=1.34$），故 $C_2$ 是倍率类参数中对寿命衰减最直接的负向因素；数值上由剂量模型，$C_2$ 每提高 1C，$\log_{10}$ 寿命约下降 0.15（寿命约衰减 29\%）。

\textbf{4. 充电时间 $T$。}$T=60\left[Q_1/(100C_1)+(80-Q_1)/(100C_2)\right]$ 是 $C_1$、$C_2$、$Q_1$ 的综合指示：充电越温和、耗时越长，对应的有效损伤剂量越小，寿命越长（偏相关 $+0.376$）。

\subsection{不同 SOC 区间高倍率影响的差异}

由第 \ref{sec:phys} 节的物理模型可直接回答这一问题：剂量模型中两个阶段的单位电量损伤系数 $|m_2|=0.424$ 比 $|m_1|=0.367$ 高约 16\%，且拟合得到的 $f(\mathrm{SOC})$ 在中高 SOC 区间显著更高（$f(80\%)=1.34$ vs $f(0)=1.00$），即相同电量在中高 SOC 区间造成的寿命损伤显著大于低 SOC 区间。因此，不同 SOC 区间内高倍率充电对寿命衰减的影响存在显著差异，中高 SOC 区间的高倍率充电是寿命衰减的主导因素。

\subsection{交互作用分析}\label{sec:interact}

在回归中引入交互项（表 \ref{tab:interact}）：$C_1\times Q_1$ 为负（$-0.0042$），反映低 SOC 高倍率剂量的累积伤害；$C_2\times Q_1$ 为正（$+0.0046$），因 $Q_1$ 越大、第二阶段覆盖区间（$80-Q_1$）越小、$C_2$ 暴露越短，从交互角度印证 $C_2$ 的伤害与其中高 SOC 覆盖量成正比。

\section{问题三：基于早期循环数据的寿命预测模型}

\subsection{特征提取}

基于逐循环放电容量（Qd）、SOH 与充电时间序列，对每个电池在前 $k$ 个循环窗口（$k=5/10/20/50/100$）内提取三类特征：（1）早期衰减特征：$k$ 处 SOH 与容量损失、SOH 线性拟合斜率及其 $R^2$、残差与一阶差分标准差；（2）充电时间特征：首循环与 $k$ 处充电时间、斜率、差分标准差与漂移；（3）潜伏时间特征：SOH 首次低于各阈值（99.9$\sim$96\%）的循环序号。另将策略参数（$C_1,Q_1,C_2$、平均充电时间）作为可用特征用于消融。

图 \ref{fig:fig19} 显示不同寿命电池前 60 循环的 SOH 已呈系统差异（短寿命电池早期 SOH 更低、波动更大），这正是早期特征能预测寿命的根本原因。

\subsection{预测模型与评估方法}

以 $\log_{10}$（循环寿命）为目标，比较三种模型：Ridge 回归、随机森林（RF）与梯度提升回归树（GBM）。采用 5 折$\times$8 次重复交叉验证，以平均绝对百分比误差（MAPE，基于反变换寿命）与 $\log_{10}$ 尺度 $R^2$ 评价。三种模型的对比（表 \ref{tab:window}）显示，GBM 在中短期窗口（$k\le20$）下 MAPE 最低，能自适应地刻画特征间的非线性交互（例如充电时间漂移与 SOH 波动对寿命的联合作用），且对早期特征中的少量异常值鲁棒；长窗口（$k\ge50$）下 Ridge 略优。本文以 $k=20$ 的 GBM 作为主预测模型。

\textbf{预测流程与公式。}寿命预测的完整流程如图 \ref{fig:fig23} 所示：由电池前 $k$ 个循环的 SOH、放电容量与充电时间序列提取特征向量 $\mathbf{x}=(x_1,x_2,\ldots,x_d)$，输入训练好的 GBM 模型得到 $\log_{10}$ 寿命预测值，再反变换得到寿命估计：
\begin{equation}\label{eq:predict}
\hat{L} = 10^{\hat{y}},\qquad \hat{y} = f_{\mathrm{GBM}}(\mathbf{x}) = \sum_{m=1}^{M} \eta\, h_m(\mathbf{x}),
\end{equation}
其中 $h_m(\cdot)$ 为第 $m$ 棵决策树、$\eta$ 为学习率。预测得到的是“达到 80\% SOH（0.88 Ah）阈值”的循环寿命估计值；对指定 SOH 阈值 $\theta$，亦可基于早期衰减斜率与潜伏时间特征估计达到该阈值的循环数。

\section{问题四：兼顾充电时间与寿命衰减的策略优化模型}

\subsection{充电时间模型}

充电时间为快充段（0$\sim$80\% SOC）耗时。理想物理模型为
\begin{equation}\label{eq:T-ideal}
T = 60\cdot\frac{Q_1/100}{C_1} + 60\cdot\frac{(80-Q_1)/100}{C_2}\ \text{min}.
\end{equation}
实测数据显示高倍率下因电压限流导致实际耗时高于理想值，故拟合经验校准模型：
\begin{equation}\label{eq:T-cal}
T = 35.51\cdot\frac{Q_1/100}{C_1} + 35.00\cdot\frac{(80-Q_1)/100}{C_2} + 5.45,\quad R^2=0.379,\ \text{MAE}=0.49\ \text{min}.
\end{equation}
系数显著小于理想值 60，反映高倍率阶段受电压窗口限制、有效电流低于名义值；截距项刻画固定过程开销。

校准模型的验证结果见图 \ref{fig:fig13}：预测值与实测值相关系数 $r=0.62$，平均绝对误差 0.49 min（约为均值 11.6 min 的 4.3\%）。$R^2=0.379$ 相对不高，主要原因是\textbf{各策略的充电时间本身集中在 9.6$\sim$14.1 min 的窄区间}（总方差仅 0.68），目标变量变化范围小导致 $R^2$ 天然受限；而模型对“策略 $\rightarrow$ 充电时间”的系统趋势拟合良好（MAE 仅 0.5 min），剩余误差主要来自同策略电池间的个体差异（约 15\% 方差）与高倍率阶段电压限流引起的非线性。对设计阶段的充电时间估计而言，MAE 是更有意义的精度指标，故该模型足以支撑第 9.5 节的优化。同时，这一窄区间也印证了第 6.3 节“充电时间并非寿命差异主要来源”的结论。

\subsection{寿命--策略响应面}

为估计不同充电策略下的 SOH 衰减，采用“先验--后验”结合的方式利用问题三的寿命预测模型：（1）\textbf{设计阶段（无实测数据）}：候选策略尚无早期循环数据，采用第 \ref{sec:phys} 节的剂量寿命模型作为设计级寿命预测，估计其期望寿命与 SOH 衰减速率；（2）\textbf{运行阶段（有早期数据）}：一旦策略投入运行并积累前若干次循环数据，即可用问题三的早期循环预测模型（第 8 节）滚动更新寿命与 SOH 衰减估计，提高准确性。设计级寿命预测模型为
\begin{equation}\label{eq:life-surface}
\log_{10}(L) = 4.311 - 0.367\,m_1 - 0.424\,m_2.
\end{equation}

\subsection{多目标优化与 Pareto 前沿}

\subsection{固定充电时间/固定寿命下的策略权衡对照}\label{sec:iso}

为直接回答“给定充电时间，哪种策略更长寿”与“给定寿命目标，哪种策略充电更快”，在观测策略中分别固定充电时间与固定寿命目标进行对照（表 \ref{tab:iso}）。

\subsection{多分段策略与可调权重优化}

将充电策略推广为 $N$ 段分段形式：0$\sim$80\% SOC 划分为 $N$ 段（边界 $s_0=0<s_1<\cdots<s_N=80\%$），第 $i$ 段以倍率 $I_i$ 充电。充电时间与寿命响应为
\begin{equation}\label{eq:multi}
T=60\sum_{i=1}^{N}\frac{s_i-s_{i-1}}{I_i},\qquad
\hat{L}=10^{4.311-0.367\,m_1-0.424\,m_2},
\end{equation}
其中 $m_1$、$m_2$ 为低/中高 SOC 区间的总高倍率电量剂量（第 \ref{sec:phys} 节定义）；两段式策略 $C_1$--$Q_1$--$C_2$ 是 $N=2$ 的特例。

不同使用场景对充电时间与寿命的偏好不同，构建可调权重的综合目标
\begin{equation}\label{eq:obj}
\min_{\{I_i,s_i\}}\; F(\alpha)=\alpha\,\frac{T-T^{\min}}{T^{\max}-T^{\min}}-(1-\alpha)\,\frac{\log\hat{L}-\log L^{\min}}{\log L^{\max}-\log L^{\min}},\quad \alpha\in[0,1],
\end{equation}
其中 $\alpha$ 为充电时间权重、$1-\alpha$ 为寿命权重。表 \ref{tab:weight} 给出不同 $\alpha$ 下在设计邻域内寻优的推荐策略：$\alpha$ 较小（重寿命）时推荐低倍率长充电时间策略；$\alpha$ 较大（重时间）时推荐高倍率快充策略；$\alpha=0.5$（均衡）即第 9.4 节的膝点推荐 3.6C(80\%)-3.6C。注意 $\alpha\le0.4$ 时推荐策略的预测寿命已超出观测数据范围（最大实测 2235），属模型外推，需谨慎对待。

\subsection{突破两段式：多段阶梯充电策略优化}\label{sec:multistage}

前述网格寻优仅在实验已有的两段式策略参数空间内搜索，本质上是对已知策略的排列择优而非真正的设计创新。本小节利用第 \ref{sec:phys} 节物理模型的结论——中高 SOC 区间降速是延长寿命的关键——在剂量模型框架下搜索任意 SOC 分段的多段阶梯式充电策略。

对于 $m$ 段阶梯式策略 $\{(I_1, \mathrm{SOC}_1), \ldots, (I_m, 80\%)\}$，以 40\% SOC 为界将各段的充电电量分别归入 $m_{\mathrm{low}}$ 和 $m_{\mathrm{mid}}$，充电时间用量模型逐段累加。设计 15 个候选策略（两段 baseline 4 个、三段 9 个、四段 2 个），三段式采用``高倍率起步$\rightarrow$中等过渡$\rightarrow$低倍率收尾''的阶梯降速模式。

\subsection{合理性、适用范围与外推风险}

（1）\textbf{合理性}：推荐策略以``中高 SOC 区间低倍率充电''为核心机理（$m_{\mathrm{mid}}\approx0$），在几乎不延长充电时间（13.3 min）的前提下实现长寿，与问题二物理模型结论一致。多段策略进一步将这一原则系统化——用阶梯降速在缩短充电时间和控制析锂风险之间取得更精细的平衡。

（2）\textbf{适用范围}：模型基于 A123 18650 LFP 电池在给定实验协议下的数据，适用于同类型电池、0$\sim$80\% 快充段、常温条件；批次间存在系统性差异，绝对寿命预测应按目标批次重新标定。

（3）\textbf{外推风险}：优化结果被严格限制在实测参数水平及其剂量覆盖范围之内，未对未经验证的高倍率--高 SOC 组合（如 8C 充至 80\%）外推；若扩展至高倍率或更宽 SOC 区间，应补充实验数据并重新拟合，避免线性模型在支持域外失效。

（4）\textbf{工程实现考虑}：推荐策略为两段式恒流充电（3.6C 至 80\% SOC 后 1C CC-CV），工程上易于在现有充电机与电池管理系统（BMS）中实现——只需将 BMS 的充电电流-电压曲线按该方案配置即可。实际落地时还应注意：低温下 3.6C 充电可能导致负极析锂风险上升，需结合温度约束动态降额；CC-CV 阶段的 80\%$\sim$100\% 补电时间受电化学极化影响，应在总补能时间估算中一并计入。这些工程细节不改变本文的定性结论，但影响具体的参数标定。

% ==================== 十、模型的检验与灵敏度分析 ====================
\section{模型的检验与灵敏度分析}

\subsection{寿命模型交叉验证}

采用 5 折交叉验证检验剂量寿命模型的预测稳定性：在全部 standard 数据上 $R^2=0.608$；而单独在批次 1 内交叉验证，$R^2=0.848$。两者差异说明模型在批次内解释力强、预测稳定，跨批次合并数据则稀释了预测精度，进一步印证了批次差异的存在。

\subsection{留一批次外推检验}

为定量刻画批次差异，做留一批次外推检验：用批次 1 训练、批次 2 检验，寿命 MAPE 达 64\%（$R^2<0$）；反向亦为 38\%（$R^2<0$）。这说明\textbf{绝对寿命的跨批次外推不可靠}，模型捕获的是批次内的相对关系，与第 5 节“批次差异说明”及第 9 节“绝对寿命预测应按目标批次重新标定”的结论一致。因此，本文推荐策略的价值在于给出批次内的最优相对设计，而非跨批次的绝对寿命保证；实际部署时需结合目标批次数据重新标定后再做绝对寿命判断。

\subsection{推荐策略灵敏度分析}

对推荐策略 3.6C(80\%)-3.6C 的三个参数分别施加扰动，考察充电时间与预测寿命的变化（表 \ref{tab:sens}）：
\begin{itemize}
\item \textbf{$C_1$ 是主要敏感参数}：$C_1$ 每变化 $\pm0.4$C，充电时间反向变化约 6\%$\sim$8\%，预测寿命反向变化约 24\%$\sim$31\%，二者权衡明显——$C_1$ 提高可加速充电但明显缩短寿命。实际执行中应重点保证 $C_1$ 的准确性。
\item \textbf{$Q_1$、$C_2$ 扰动影响可忽略}：因 $Q_1=80\%$ 时第二阶段覆盖为零、$C_2$ 不参与快充段充电，故 $C_2$ 的扰动不影响结果，$Q_1$ 略降影响也甚微。这提示推荐策略对 $C_2$、$Q_1$ 的小幅执行偏差具有鲁棒性。
\end{itemize}

% ==================== 十一、模型评价、改进与推广 ====================
\section{模型评价、改进与推广}

\textbf{模型优点。}（1）机理与数据结合：剂量模型以“高倍率电量在 SOC 轴上的分布”刻画老化，系数符号与电化学机制一致；（2）充分考虑混杂与批次差异：引入批次虚拟变量控制批次混杂；（3）预测模型经 5 折$\times$8 次重复交叉验证，避免过拟合；（4）优化约束合理，避免过度外推。

\textbf{模型不足与改进。}（1）问题二回归仅解释约 68\%（含批次）的寿命方差，可引入温度、内阻等逐循环协变量提高解释力；（2）问题三长期 SOH 预测精度较低（$t\ge800$ 时 $R^2$ 波动、MAE 约 3.5\%），可结合电化学机理或序列模型刻画长期非线性衰减；（3）问题四未考虑电流阶跃、温度约束等工程细节，落地需结合热管理仿真验证。

\textbf{模型推广与建模方法总结。}本框架可推广至其他电池体系与充电协议，只需重新拟合剂量-寿命响应面与早期预测特征。本文的“整理--量化--预测--优化”闭环方法将电化学机理认知转化为可计算的剂量-响应关系，使快充策略设计从经验试错走向定量寻优。

% ==================== 十二、结论 ====================
\section{结论}

本文围绕快充策略对锂离子电池寿命衰减的影响，完成了“数据整理 $\rightarrow$ 量化建模 $\rightarrow$ 寿命预测 $\rightarrow$ 策略优化”四个递进环节，主要结论如下：

\begin{enumerate}
\item \textbf{数据与寿命分布}：完成 124 个电池策略参数、寿命、SOH 曲线与充电时间的系统整理；寿命跨度约 15 倍（148$\sim$2235），策略影响极显著；三个批次寿命中位数分别为 841、481、964。
\item \textbf{量化模型}：$C_2$ 是主要的负向倍率策略因素（含批次标准化系数 $-0.039$，偏相关 $-0.249$），充电时间 $T$ 与寿命正相关（偏相关 $+0.376$）；单位高倍率电量在中高 SOC 区间的寿命损伤比低 SOC 区间高约 16\%（$m_2$ $-0.424$ vs $m_1$ $-0.367$），物理模型以 SOC 损伤权重函数 $f(\mathrm{SOC})$ 刻画了这一区间敏感性的本质——中高 SOC 区间单位电量的损伤权重更高（$f(80\%)=1.34$ vs $f(0)=1.00$）。
\item \textbf{寿命预测}：基于早期 20 个循环特征（SOH 衰减率、波动、充电时间漂移），GBM 模型交叉验证 MAPE=14.7\%、$R^2=0.77$；充电时间特征（首循环值与波动）为主导特征；近中期 SOH 预测误差小于 1.2\%，长期 SOH 存在不可约不确定性。
\item \textbf{策略优化}：在实验覆盖邻域内得到 Pareto 前沿，推荐两段式 3.6C(80\%)-3.6C（充电 13.3 min、实测寿命 2081）。突破两段式局限，首次实现任意 SOC 分段的多段阶梯充电优化：最优三段式 3C→45\%→2C→65\%→0.8C 预测寿命达 3868 次（+160\%），平衡型 3.6C→50\%→2C→70\%→1C 在 17.3 min 下实现 2623 次预测寿命，所有外推策略均经 PyBaMM 单循环析锂验证安全性。
\end{enumerate}

\textbf{展望。}本框架可进一步：将温度、内阻等协变量纳入剂量模型以解释个体差异；引入电化学机理模型提升长期 SOH 预测外推能力；将优化推广到任意 SOC 分段并叠加温度、电压约束，得到更贴近工程实际的充电方案。
